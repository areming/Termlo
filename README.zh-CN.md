# Termlo · 中文介绍

[返回首页中文部分](README.md#中文) · [English](README.md#english)

Termlo 是本地优先的 SSH、SFTP 与服务器智能体桌面工具。桌面端使用 Electron 与 JavaScript，不依赖 REA 的 Rust 运行时。首页已改成中英双语，点击上方链接即可在同一个首页查看介绍。

查看[主机与项目空间](docs/intro/hosts.md)、[终端与 SFTP](docs/intro/terminal.md)、[智能助手](docs/intro/agent.md)和[账户服务部署](docs/intro/account-api.md)。所有介绍图均为虚构数据制作的示意图。

安装包见 [GitHub Releases](https://github.com/areming/Termlo/releases)。普通 SSH 使用无需登录；如需邮箱密码账户，在助手顶部选择“账户服务”，选定一台主机后发起部署。服务接口与 Swagger 详见[用户 API 文档](services/user-api/README.md)。
