# 终端与文件 / Terminal and files

![虚构终端与文件连接示意](../images/terminal.svg)

示意图中的命令与文件是虚构内容。SSH 终端支持多个标签、跳板机和服务器指纹核对。命令、地址、状态等可按类别着色，也能切换回原始终端配色。SFTP 可直接选择已保存主机连接，不必先打开终端；上传、下载与路径浏览在独立页面完成。

Commands and files in the illustration are fictional. SSH supports multiple tabs, saved jump hosts, and host-key verification. Highlight categories can be toggled off to show the terminal's original colors. SFTP opens its own connection to a saved host, without requiring an SSH terminal tab.
