![虚构主机界面示意](../images/hosts.svg)

图中主机名、配置与 `192.0.2.0/24` 文档地址均为虚构示意。Termlo 将主机归入当前账户的项目空间；切换空间会切换主机与助手可选范围。主机卡片显示识别出的操作系统、连接后获取的配置与资源概况；更多菜单可移动或复制到已知空间。识别与监控取决于远端能否提供信息。

The illustration contains fictional hosts and documentation-only addresses. Hosts belong to a project space under the current account. Switching spaces changes the visible hosts and the agent's selectable scope. The host card can show detected OS and resource details after connection; the menu can move or copy a host to a known space. Detection depends on what the remote host exposes.
