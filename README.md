# Termlo

<img src="assets/termlo.png" alt="Termlo logo" width="80" height="80">

**SSH / SFTP 桌面客户端，内置一个守规矩的服务器助手。**
终端、文件、助手三件事做好：每一步看得见，改过的文件能撤销，密码和密钥只留在本机。

*A local-first SSH/SFTP desktop client with a constrained server assistant: every step is visible, file changes can be undone, and secrets never leave your machine.*

## 能做什么

- **主机**：卡片或列表，按分组整理，可拖动排序；在线的主机直接显示 CPU、内存、磁盘、网速走势。支持密码、私钥和多级跳板机（最多 4 级），可从 `~/.ssh/config` 导入。首次连接核对服务器指纹。
- **终端**：多标签、Ctrl F 查找、字号和字体可调、语义高亮（提示符、路径、IP、错误 / 警告）；底部状态栏显示这台主机的实时负载。断线后按 Enter 重连。
- **文件**：浏览服务器目录，把本机文件拖进来就上传（拖到文件夹上就传进那个文件夹）；文件夹上传下载、传输队列、同名冲突处理（覆盖 / 跳过 / 保留两者）；文件管理都在右键菜单里。
- **助手**：用一句话说目标。查看类的问题直接回答；要改动、步骤多的，先给方案，你点"执行方案"后它自己做完并逐项验证。命令和输出作为可展开的行嵌在对话里。
  - **在终端里直接用**：在命令行输入 `# 一句话` 回车，助手就在这个终端里查看、思考、动手，过程和结论直接显示在终端里；需要你决定时用 ↑↓ 选择、↵ 确认。回答后可以接着问，Esc 回到命令行。选中终端输出右键"问 AI"，把这段输出交给它看。
  - **危险操作先问你**：删数据、停止或重启服务、重启机器、改防火墙 / SSH / 账户、卸载软件、下载脚本直接执行等，会先停下给出确切的命令，你允许了才执行，只放行这一次。
  - 改文件前必须先读过同一个文件，改动会自动备份，可以撤销。
  - 结果由检查项说话：有检查没通过，就不会标成"已完成"。
  - 最多 4 个对话同时进行；同一台主机上的改动会排队，不会互相踩到。对话按主机归类，从主机进入会接着它最近的对话。
  - 支持任何兼容 OpenAI 的接口；可以设置备用模型，主模型限流或额度用完时自动接力。
- **桌面**：关闭窗口后留在托盘，终端不断（可在设置里关掉）；只运行一个实例；Ctrl K 搜索主机和操作；深浅两套主题。第一次打开有三步上手引导，顶栏 ? 是使用说明；装好后会自动检查新版本。

## 安全边界

- 助手拥有你所选 SSH 账户的权限，只能操作这次对话选中的主机。它用自己的连接执行命令，不会往你打开的终端里敲字。
- 命令输出（以及你交给它的终端内容）会发给你配置的模型服务。密码、私钥和常见令牌在发送前会被隐藏；少于 8 个字符的密码无法可靠隐藏，添加主机时和第一次用到时会提示。
- 撤销只覆盖助手通过"修改文件"做的改动；通过命令安装软件、启动服务等操作需要另行检查。
- SSH 密码、私钥口令和模型密钥用系统加密保存在本机，不上传。

## 下载

从 [Releases](https://github.com/areming/Termlo/releases) 下载：Windows x64、macOS Intel、macOS Apple Silicon。装好后会自动检查新版本（设置里可以关）。

安装包暂未签名：
- Windows 如果提示"已保护你的电脑"，点"更多信息" → "仍要运行"。
- macOS 如果提示"无法打开"，在"访达"里右键 Termlo → "打开"，或到"系统设置 → 隐私与安全性"里点"仍要打开"。

从 1.x 升级时，所有空间（包括已登录账户下的空间）里的主机会合并到同一个列表，原空间名变成分组；服务器指纹和模型设置一并迁移。1.x 的助手任务历史不迁移，旧文件保留在数据目录里不动。

## 开发

需要 Node.js 24.13+：

```sh
npm ci
npm test          # 单元测试
npm run test:ui   # Electron 端到端冒烟测试（本地 SSH 夹具 + 脚本化模型）
npm start
```

- 打包：`npm run dist:win` / `npm run dist:mac`（需在对应系统上运行）。推送 `v*` 标签后，GitHub Actions 会构建三个平台的安装包，并以 `RELEASE_NOTES.md` 作为 Release 说明发布。
- 助手基准：`node scripts/bench.cjs`，用真实模型在一台可丢弃的服务器上跑部署和修复任务，结果由服务器上的检查命令判定。配置写在 `~/.config/termlo/bench.env`，不要用生产服务器。
- 本地数据目录为 `Termlo`（2.0.1 及更早版本的 `Termus` 目录会在首次启动时整体改名过来）。

本仓库尚未选择开源许可证。
